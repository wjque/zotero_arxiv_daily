- Defined the curated corpus as an evolving local judgment source rather than a fixed dataset.

  reproducible evaluation pins an immutable corpus revision, digest, cutoff, and split identities.
- Changed personalized screening-criteria activation from a possible daily update to a guarded
  weekly cadence. Feedback events may still be ingested on scheduled runs, but daily recommendations
  use the last successful weekly aggregate snapshot.
- Added requirements for configurable weekly eligibility in `Asia/Shanghai`, deterministic event
  cutoffs, minimum-sample no-ops, stable-anchor and rolling evaluation windows, accumulated-event
  recovery after missed or failed runs, atomic activation, versioned rollback, and injected-clock
  boundary tests.
- Kept automatic weekly learning limited to bounded derived preference aggregates. Prompt, rubric,
  security, exploration, and production-weight changes remain separately versioned and explicitly
  activated.
