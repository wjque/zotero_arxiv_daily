# 2026-08-20

## Summary

- Implemented V030-M3 controlled candidate coverage on
  `feature/v0.3-controlled-coverage` while preserving v0.2.1 as the production discovery default.

## Added

- Added a deterministic planner that maps allowlisted protected-profile facets to at most four
  cross-category arXiv bridge queries and accepts bridge candidates through local public-text
  matching.
- Added a `controlled-shadow` retrieval mode that requires a separate ignored candidate-state path
  and reports query, request, and bridge-candidate counts.
- Added synthetic bridge-paper, empty-profile, malformed-metadata, deduplication, partial-failure,
  ordering, query-budget, request-budget, and candidate-budget coverage.
- Recorded the privacy and activation boundary in ADR-0009.

## Changed

- Refactored retrieval to consume typed discovery queries, reserve a bounded bridge-candidate budget,
  reject oversized provider pages, and abandon partial results on any provider failure.
- Kept the scheduled workflow on the exact released category-only path; controlled discovery remains
  local shadow behavior pending V030-M6 operator approval.

## Tests and Verification

- Repository-wide `ruff format --check`, `ruff check`, strict `mypy`, and 269 offline tests passed.
- Targeted discovery, retrieval, CLI, workflow-hardening, and Atom contract suites passed with 54
  tests.
- All 8 desktop/mobile Chromium tests passed, workflow YAML parsed successfully, and the wheel and
  source distribution built successfully.
- Static-site, package-content, changed-file credential, private-data, and local-path artifact checks
  passed.

## Compatibility and Migration

- No persisted schema changed. Existing public candidate-state files and the v0.2.1 discovery path
  remain valid.
- Remote arXiv requests contain only category and date constraints. Protected facet values remain
  local and no private profile content is added to candidate or browser artifacts.

## Follow-ups

- Production activation remains deferred until V030-M6 policy comparison and explicit operator
  approval.
