## Added

## Changed

- Expanded the proposed v0.1.1 plan with milestone `V011-M5` for bounded static-site visual and
  usability refinement. The milestone requires responsive layout, status and recommendation-card
  hierarchy, light/dark color support, localized labels, accessibility checks, self-contained
  assets, and explicit size budgets without a frontend-framework migration.
- Renumbered repetition/deployment hardening to `V011-M6` and release verification to `V011-M7`.
- Changed the production cron to `10:30 UTC` (`18:30 Asia/Shanghai`) and added actual-time guards:
  delayed scheduled jobs skip model work while manual peak-time jobs require the explicit override.
- Upgraded and pinned checkout v6.1.0, setup-python v6.3.0, configure-pages v6.0.0,
  upload-pages-artifact v5.0.0, and deploy-pages v5.0.0 at reviewed immutable revisions with Node.js
  24-compatible runtimes.
- Bumped the authoritative application version to `0.1.1` for release verification and updated the
  README, configuration example, and unreleased changelog.

## Fixed

- Converted arXiv publication instants to `Asia/Shanghai` before deriving browser filter dates,
  preventing UTC/local-midnight misclassification.
- Ensured fully suppressed or empty eligible batches make no provider request and failed, skipped,
  or partially deployed runs do not advance recommendation history.
- Fixed state-branch persistence after production smoke run `30732033140` exposed that the new
  local worktree branch was based on `main`, causing a non-fast-forward push after Pages deployed.
  Persistence now bases the worktree explicitly on `origin/state` when prior state exists.
